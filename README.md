# S59 Events — сайт з адмін-панеллю

Сайт агенції чотирма мовами (EN · PL · UA · RU) з адмін-панеллю, калькулятором вартості, формою заявок та інтеграцією з CRM.

- **Сайт:** `/en/`, `/pl/`, `/uk/`, `/ru/` (головна `/` сама обирає мову за браузером відвідувача)
- **Адмін-панель:** `/admin`

## Що можна робити в адмін-панелі

| Розділ | Що там |
|---|---|
| Заявки | Усі заявки з сайту, статуси, нотатки, експорт у Excel/CSV, повторне надсилання в CRM |
| Тексти сайту | Будь-який текст кожної сторінки для кожної мови: змінити, видалити, додати пункти, послуги, питання FAQ |
| Портфоліо | Проєкти з фото, відео, описом чотирма мовами |
| Відгуки | Відгуки клієнтів з фото |
| Фото та відео | Завантаження файлів (до 300 МБ кожен) |
| Дизайн | Кольори, шрифти (Google Fonts), логотип, фото/відео першого екрана, фото послуг, порядок і видимість блоків головної, власний CSS |
| Калькулятор | Ціни за типом події, за гостя, коефіцієнти пакетів, додаткові опції |
| Контакти | Телефон, WhatsApp, email, Instagram, Telegram, дані компанії |
| CRM та сповіщення | Webhook (HubSpot, Pipedrive, Bitrix24, KeyCRM, Make, Zapier…), Telegram-бот, email (SMTP), автовідповідь клієнту |
| Мови та SEO | Увімкнення мов, мова за замовчуванням, домен, код аналітики, приховування від Google |
| Безпека та копії | Зміна пароля, резервна копія та відновлення |

Підказка для текстів: `*слово*` — курсив, `**слово**` — жирний, порожній рядок — новий абзац.

## Запуск на Railway

1. **New Project → Deploy from GitHub repo** → оберіть цей репозиторій (і гілку, якщо код не в `main`).
2. **Variables** сервісу → додайте:
   - `ADMIN_PASSWORD` — пароль для входу в `/admin` (мінімум 8 символів; потім його можна змінити в адмінці)
   - `NODE_ENV` = `production`
3. **Volume (обов'язково):** правою кнопкою на сервіс → **Attach Volume** → Mount path: `/data`.
   Без нього заявки, тексти та фото зникатимуть після кожного перезапуску.
4. **Settings → Networking → Generate Domain** — сайт отримає адресу `*.up.railway.app`.
   Свій домен (наприклад, `s59events.com`) додається там же: **Custom Domain** → внесіть DNS-записи, які покаже Railway.
5. Відкрийте `https://ваш-домен/admin`, увійдіть з паролем і пройдіться по розділах:
   - **Контакти** → впишіть email агенції
   - **Калькулятор** → замініть приклади цін на свої
   - **Дизайн** → завантажте фото/відео для першого екрана та послуг
   - **Мови та SEO** → впишіть адресу сайту
   - **CRM та сповіщення** → підключіть Telegram або email, щоб одразу бачити нові заявки

Railway автоматично знаходить Volume (змінна `RAILWAY_VOLUME_MOUNT_PATH`), тож нічого більше налаштовувати не треба.

## Локальний запуск

```bash
npm install
ADMIN_PASSWORD=yourpassword npm start
# http://localhost:3000
```

Потрібен Node.js 22.13 або новіший. Дані зберігаються в `./data` (або в `DATA_DIR`).

## Структура

```
server.js            сервер, маршрути, API адмінки
src/render.js        шаблони сторінок сайту
src/content/*.json   початкові тексти чотирма мовами
src/defaults.js      початкові налаштування (кольори, шрифти, ціни, контакти)
src/notify.js        надсилання заявок у CRM / Telegram / email
src/db.js            база даних (SQLite)
public/              стилі, скрипти, логотип
admin/               адмін-панель
docs/                структура сайту, тексти та бренд-матеріали
```
